- 关键坑:
  1. venv 是 Python 3.12,x86 venv 必须同版本(.so 文件名带 cpython-3XX 标签,不一致无法 lipo 合并)
  2. cryptography 50.0.0 的 x86_64 轮子在 Rosetta 下报 _BIO_ADDR_free 符号错误;降到 44.0.2 后两侧统一版本才能合并成功(纯 Python 层与 .so 版本必须一致,否则 XOFHash AttributeError)。requirements.txt 已固定 ==44.0.2
  3. PyInstaller 缓存更新会被安全删除策略拦截,需 PYINSTALLER_CONFIG_DIR 指到项目内且版本变更时手动 trash 缓存目录
  4. 构建产物清理用 mv 到 ~/.Trash,避免 rm -rf 被拦
- x86_64 工具链:.tools/python312(python-build-standalone x86_64 cpython 3.12.14,免 sudo);venv-x86 已建并装好与主 venv 相同版本依赖(除 cryptography==44.0.2 两侧一致)
