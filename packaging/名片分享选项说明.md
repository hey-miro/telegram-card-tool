# 真实名片分享 - 选项说明

## 号码格式

每行一个号码，支持两种写法：

```
手机号
手机号;姓名;姓氏
```

示例：

```
+5581995962517
+5581995962518;张三
+8613812345678;李;四
```

- 不写姓名时，工具会按下方规则自动补全姓名
- 国际号码建议带国家区号，如 `+86`、`+55`

---

## 轮数

同一批号码重复发送的轮数。

- 默认 `1`，即每个号码发一次
- 设为 `2` 时，每个号码会依次发两遍

---

## 发送间隔（秒）

每发送一条名片后等待的秒数。

- 默认 `15`
- 后端最低允许 `1` 秒；建议保持默认值或更高。Telegram 没有公开固定安全间隔

---

## 每批消息数 / 批次冷却

- 默认每批 `20` 条实际消息
- 默认每批结束冷却 `300` 秒
- 批次数按实际发送消息计算。例如 20 个号码发送到 2 个群等于 40 条消息，会拆成 2 批
- 冷却期间任务显示“等待中”，可以随时停止

---

## 回退名 / 回退姓

当号码**没有填写姓名**、**也查不到 Telegram 真实姓名**时，使用的备用姓名。

示例：回退名填 `客服`，回退姓留空，则所有无名号码发出去都显示 **客服**。

---

## 复选框

### 自动获取对方 Telegram 账号姓名

- 未勾选：只使用你填的姓名或回退姓名
- 勾选：工具自动查询该号码对应 Telegram 账号**资料上设置的名字**并优先使用
- 查不到资料名时，按回退名 / 自动命名处理

### 跳过未注册号码

- 未勾选：所有号码都会尝试发送，没注册 Telegram 的号码会发出"死卡片"（无按钮）
- 勾选：发送前先检测，**只发送已注册 Telegram 的号码**，避免白发
- **建议始终勾选**

### 无姓名自动命名

- 未勾选：没有姓名的号码会被跳过
- 勾选：没有姓名时自动命名为 **"联系人+尾号"**，如 `联系人2517`
- 与回退名同时存在时，**回退名优先**

---

## 姓名优先级

一个号码最终显示什么姓名，按以下顺序决定：

```
1. 号码后填写的姓名（如 13800138000;张三）
2. Telegram 账号资料姓名（勾选「自动获取对方 Telegram 账号姓名」时）
3. 回退名 / 回退姓
4. 自动命名"联系人+尾号"（勾选了"无姓名自动命名"时）
```

---

## 推荐配置

做推广时建议这样设置：

| 选项 | 推荐值 |
|---|---|
| 轮数 | 1 |
| 发送间隔 | 15 秒或更高 |
| 每批消息数 | 20 |
| 批次冷却 | 300 秒 |
| 回退名 | 填一个通用名，如 `客服`、`经理` |
| 自动获取对方 Telegram 账号姓名 | 可选 |
| 跳过未注册号码 | ✅ 勾选 |
| 无姓名自动命名 | ✅ 勾选 |

这样能保证：死号跳过、活号一定有名字、发送稳定不易被限流。
