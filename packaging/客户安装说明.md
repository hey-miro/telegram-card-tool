# Telegram 名片工具 - 客户安装说明

## macOS 版

1. 解压 zip 压缩包（双击或右键「打开」）
2. **首次打开**：双击文件夹里的「首次打开-双击我.command」即可启动
   - 也可以手动：右键点「Telegram名片工具」→「打开」→ 再点「打开」
   - 系统提示「无法验证开发者」是正常现象（软件未购买苹果开发者证书），软件本身安全
3. 之后每次使用：直接双击「Telegram名片工具」图标即可
4. 软件同时支持 Apple Silicon（M 系列）和 Intel 芯片的 Mac

## Windows 版

1. 解压 zip 压缩包（右键 → 全部解压缩）
2. 进入文件夹，双击 `TelegramCardTool.exe` 启动
3. 首次启动如出现蓝色窗口提示「Windows 已保护你的电脑」：
   点「更多信息」→「仍要运行」即可（未购买代码签名证书的正常提示）
4. 请勿删除文件夹里的其他文件（dll 等），建议发送快捷方式到桌面使用

## 激活授权

1. 启动软件后，在授权页面输入我们提供的**授权码**，点击激活
2. 授权码与设备绑定，更换电脑请联系我们重置
3. 授权到期后可联系续期，输入新授权码即可

## 常见问题

| 问题 | 处理 |
|---|---|
| 任务显示“等待中” | 正在批次冷却或处理短时限流，倒计时后从当前名片继续 |
| 提示账号熔断 | 不要立即重启任务，请等待后通过 @SpamBot 检查账号状态 |
| 发送验证码超时 | 检查网络（Telegram 需要稳定网络环境），稍后重试 |
| 授权激活失败 | 确认授权码输入无误、网络正常；仍失败联系管理员 |
| macOS 提示文件损坏 | 重新运行「首次打开-双击我.command」 |
