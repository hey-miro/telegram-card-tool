# Telegram 名片工具 · 使用文档

> 支持 macOS（Apple Silicon + Intel）与 Windows
> 版本：v1.0（含网络代理支持）

---

## 一、软件简介

本工具用于**批量向多个 Telegram 群组 / 频道 / 私聊会话分享真实名片（联系人卡片）**，也支持账号管理与群组管理。

- 基于 Telegram 官方协议（Telethon），使用自有 api_id / api_hash 登录
- 仅建议操作**自有或已获授权**的账号、会话与群组
- 使用前请确保网络可以正常连接 Telegram（国内网络通常需要代理，见「四、网络配置」）

---

## 二、安装

### macOS 安装

1. 解压 `Telegram名片工具-macOS-universal.zip`（双击压缩包即可）
2. **首次打开**：双击文件夹中的 **「首次打开-双击我.command」**，即可自动解除系统限制并启动软件
   - 若提示「无法验证开发者」或「文件已损坏」，属正常现象（软件未购买苹果开发者证书），软件本身安全
   - 也可手动：右键点「Telegram名片工具」→「打开」→ 再点「打开」
3. 之后每次使用：直接双击「Telegram名片工具」图标即可
4. 通用版同时支持 Apple Silicon（M1/M2/M3 等）与 Intel 芯片的 Mac

### Windows 安装

1. 解压 `TelegramCardTool-Windows-x64.zip`（右键 → 全部解压缩）
2. 进入文件夹，双击 **`TelegramCardTool.exe`** 启动
3. 若出现蓝色窗口「Windows 已保护你的电脑」：点「**更多信息**」→「**仍要运行**」即可（未购买代码签名证书的正常提示）
4. **请勿删除**文件夹里的其他文件（dll 等），建议右键 exe → 发送到 → 桌面快捷方式

## 三、激活授权

1. 启动软件后，在授权页面输入**授权码**，点击「激活」
2. 授权码与设备绑定（一码一设备），更换电脑请联系管理员重置
3. 授权到期后软件会停止工作，联系管理员续期并输入新授权码即可

## 四、API 设置与网络配置（首次使用必做）

### 4.1 填写 api_id / api_hash

1. 打开 [my.telegram.org](https://my.telegram.org)，用你的 Telegram 账号登录
2. 进入 **API development tools** → 点击 **Create application**（应用名随意，如 `card-tool`）
3. 页面上会显示 `api_id`（数字）和 `api_hash`（一串字母数字），复制它们
4. 回到工具，点右上角 **「API 设置」**，填入 api_id 与 api_hash，点保存

> api_hash 相当于账号的密钥，**不要泄露给他人**。

### 4.2 网络配置（重要）

Telegram 服务器在国内无法直连，**连接超时是网络问题，不是软件问题**。两种解决方式任选其一：

**方式 A（推荐，最简单）：代理软件开启 TUN / 增强模式**

在 Clash、V2Ray 等代理软件中开启 **TUN 模式 / 增强模式 / 虚拟网卡模式**，即可让所有程序的网络流量自动走代理，工具无需任何额外配置。

**方式 B：在工具内显式配置代理**

1. 打开「API 设置」→ 勾选 **「启用代理」**
2. 代理类型选 `SOCKS5`（Clash / V2Ray 默认协议）
3. 代理地址填 `127.0.0.1`，端口填你代理软件监听的端口：
   - Clash 默认 `7890`
   - V2RayN 默认 `10808`
   - 具体端口以代理软件设置页显示为准
4. 保存后重新操作即可

> 工具支持 SOCKS5 / HTTP / SOCKS4 三种代理类型。
> 如果没开代理也没开 TUN 模式，发送验证码、登录、拉取会话都会超时。

## 五、登录账号

1. 进入 **「账号管理」** 页
2. 在「登录账号」区域输入手机号，格式：`+86 13800138000`（含国家区号）
3. 点击「发送验证码」
4. 在弹出的窗口输入短信验证码，点提交
   - 若账号开启了二步验证（2FA），还需输入登录密码
5. 登录成功后，账号会出现在下方「账号列表」中

> 支持同时登录多个账号；也支持在「导入 Session」粘贴 Telethon/Pyrogram 生成的 Session 字符串快速导入已有登录态。

## 六、名片分享（核心功能）

1. 进入 **「名片分享」** 页
2. 顶部选择要使用的**账号**（下拉框）
3. 点击「**拉取会话**」加载该账号的会话列表，可用筛选（频道/群组/私聊）与搜索快速定位
4. 勾选要发送名片的**目标群组 / 频道 / 私聊**（支持全选、反选、清空选择）
5. 在右侧「真实名片分享」区域输入号码列表，**每行一个号码**，支持两种写法：
   - 只发名片不填姓名：`+8613800138000`
   - 带姓名一起发：`+8613800138000;张三;张`
   - 国际号码建议带国家区号（如 `+86`、`+55`）
6. 设置参数（详细说明见下表）
7. 点击「**批量开始分享**」，下方「实时日志」会显示每条发送结果
8. 随时可点「停止」中止任务

> 默认为直接发送名片，不会把号码导入当前账号的 Telegram 通讯录。只有勾选姓名查询或跳过未解析号码时，才会进行官方限速的手机号预处理。

### 6.1 各参数说明

| 参数 | 说明 |
|---|---|
| 轮数 | 同一批号码重复发送的轮数，默认 1（每个号码发一次） |
| 发送间隔（秒） | 每条之间的等待时间，默认 15 秒 |
| 每批消息数 | 按实际发送消息计数，默认 20 条 |
| 批次冷却（秒） | 每批完成后的暂停时间，默认 300 秒 |
| 回退名 / 回退姓 | 号码没填姓名、也查不到 Telegram 姓名时使用的备用姓名（可选）。如回退名填「客服」，则所有无名号码都显示「客服」 |

### 6.2 三个复选框说明

| 复选框 | 作用 |
|---|---|
| 慢速获取 Telegram 资料姓名 | 勾选后，使用 `contacts.resolvePhone` 查询资料姓名；官方要求最多每 3 秒查询 1 个号码 |
| 跳过未解析/不可见号码 | 勾选后先慢速查询，只发当前账号可解析的号码；对方隐私设置也可能导致无法解析 |
| 无姓名自动命名 | 勾选后，没有姓名的号码自动命名为「联系人+尾号」（如：联系人8000）；与回退名同时存在时回退名优先 |

### 6.3 姓名优先级

一个号码最终显示什么姓名，按以下顺序决定（前者优先）：

```
① 号码后填写的姓名（+8613800138000;张三）
② Telegram 账号资料姓名（勾选「慢速获取 Telegram 资料姓名」时）
③ 回退名 / 回退姓
④ 自动命名「联系人+尾号」（勾选「无姓名自动命名」时）
```

### 6.4 建议初始配置

| 选项 | 推荐值 |
|---|---|
| 轮数 | 1 |
| 发送间隔 | 15 秒或更高 |
| 每批消息数 | 20 |
| 批次冷却 | 300 秒 |
| 回退名 | 填一个通用名，如「客服」 |
| 慢速获取 Telegram 资料姓名 | 默认不勾选，只在确实需要资料姓名时启用 |
| 跳过未解析/不可见号码 | 按需勾选；会使发送前预处理显著变慢 |
| 无姓名自动命名 | ✅ 勾选 |

随机间隔和固定参数不能保证不被限制；工具会优先遵守 Telegram 返回的冷却时间。

### 6.5 关于名片的「消息 / 添加」按钮

- **号码已注册 Telegram** → 卡片带头像，接收方可一键私聊
- **号码未注册或不可通过手机号查找** → 当前账号可能无法解析；需要过滤时可勾选慢速预处理
- 若号码已注册但卡片仍无按钮，需在对方账号的「设置 → 隐私和安全 → 手机号码 → 谁可以通过手机号找到我」中设为「所有人」
- 查看者若已存过该号码，卡片只显示「消息」按钮，不显示「添加」，属正常现象

## 七、群组管理

1. 进入 **「群组管理」** 页
2. 顶部选择账号 → 「拉取会话」加载列表
3. 支持按 频道 / 群组 / 私聊 筛选，按名称搜索

## 八、常见问题

| 问题 | 处理方法 |
|---|---|
| 发送验证码提示连接超时 | 网络无法直连 Telegram：开代理 TUN 模式，或在「API 设置」里配置代理（见四） |
| 任务显示“等待中” | 正在执行批次冷却或短时 FloodWait 自动暂停；倒计时后从当前名片继续，可随时停止 |
| 提示账号熔断 | `PEER_FLOOD` 等账号限制会跨重启保留；请通过 @SpamBot 检查，确认恢复后再在账号页手动解除 |
| 授权激活失败 | 确认授权码输入无误、网络可访问授权服务器；仍失败请联系管理员 |
| 授权提示「已到期」 | 联系管理员续期，输入新授权码 |
| macOS 提示「文件已损坏 / 无法打开」 | 重新双击「首次打开-双击我.command」 |
| Windows 打不开 / 报缺少 dll | 解压时选择了「快速提取」只解出部分文件，请用「全部解压缩」后保持文件夹完整 |
| 忘记二步验证密码 | 需要联系 Telegram 官方找回，工具无法绕过 |

## 九、使用建议（重要）

- **控制发送频率**：默认每条间隔 15 秒、每批 20 条、批次冷却 300 秒；Telegram 没有公开固定安全阈值，限流反馈以服务端返回为准
- **账号安全**：api_hash 与 Session 字符串请勿外泄；授权码绑定设备，请勿与他人共享
- **合规使用**：仅操作自有或已获授权的账号、会话与群组，遵守 Telegram 服务条款与当地法律法规
